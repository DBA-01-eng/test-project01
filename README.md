# AI Developer

A Node.js project written in TypeScript and built with Next.js.

## Stack

- Runtime: Node.js
- Language: TypeScript
- Framework: Next.js

## Current setup

The repository is in early setup. `dotenv` is installed for environment variables. Next.js and TypeScript are the planned application stack and are not scaffolded yet.

## Getting started

Install dependencies:

```bash
npm install
```

Environment variables belong in a local `.env` file. Do not commit that file.
